# T-Minus submission trailer

This revision replaces the earlier Mission Control walkthrough with a 29.5-second T-Minus trailer: editorial countdown, cropped gameplay, short role verbs, local M2 narration, the game’s music/effects, actual flight playback and a real 2/2 main-goal result.

`T-Minus-Submission.mp4` is the delivery file. `VIDEO-DESCRIPTION.txt` contains shareable hosting copy, credits and disclosures. `capture.mjs` and `render.py` reproduce the capture/edit with the installed local tools. Assets and source recordings are retained alongside them.

The gameplay was prepared through normal game actions with an accelerated calendar, on one local browser. This is not a human multiplayer playtest. The two optional goals were not achieved. Countdown typography is an editorial device, not the game clock.

Narration: local Voicebox Supertonic 3 M2. Music: actual game title/planning track. Effects: actual game attention, confirmation, launch and achievement sounds. AI labels are burned into the export and provenance is embedded in MP4 metadata.

The earlier `video/submission/` version is superseded. No upload, commit or push is included in this task.

Verified export: 29.500 seconds, 1920×1080, H.264/AAC. Inspected an eleven-frame contact sheet for scene order, T-Minus branding, captions and the actual 2/2 main-goal result.
