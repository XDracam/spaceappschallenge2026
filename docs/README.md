## How to keep ideas usable

1. Save new input in a dated note, with its source. Preserve original wording when practical.
2. Add or update an idea entry. Label it **user direction**, **tentative user idea**, **proposal**, **accepted**, **deferred**, or **rejected**.
3. Give unresolved choices a question ID and identify the work they block.
4. When the user accepts a choice, add a dated decision with its rationale and update the current design.
5. After an experiment, save observations and link them to the ideas and questions they inform.

Use the next unused ID; do not renumber historical records. One idea may evolve through several experiments without becoming a decision. Disagreement and unsuccessful experiments are useful history.
